# Контрольные вопросы

## 1. Чем `dotnet run` отличается от `dotnet build`? Какая команда что делает?
`dotnet build` — только компилирует код. Он проверяет ошибки и создает исполняемый файл (программу), но не запускает её.
`dotnet run` — сначала выполняет `build` (то есть компилирует), а затем сразу запускает программу. Это удобно для быстрой проверки кода.

## 2. Какие файлы появляются в `bin/Debug/net10.0/` после сборки? Что в них лежит? Зачем нужен `.pdb`?
В этой папке появляется сам исполняемый файл (например, `Lab01.dll` или `Lab01.exe`) — это наша скомпилированная программа, которую запускает компьютер.
Также там лежит файл `.pdb` (Program Database). Он нужен для отладки: в нём хранится информация о том, какая строка кода соответствует какой команде в программе. Без него отладчик не сможет показать, где именно произошла ошибка.

## 3. Что делает компилятор с вашим `.cs`-файлом перед запуском? Почему процессор не может выполнить текст исходного кода напрямую?
Компилятор переводит понятный человеку код C# в понятный компьютеру **промежуточный язык (IL)** и упаковывает его в `.dll`. 
Процессор не может выполнить текст напрямую, потому что процессор понимает только машинные команды (нули и единицы). Текст для него — просто набор символов, который он не умеет интерпретировать.

## 4. Зачем нужен `.gitignore`? Что произойдёт, если положить в репозиторий папку `bin/`?
`.gitignore` — это файл, в котором перечислены папки и файлы, которые Git должен **игнорировать** (не отслеживать и не загружать на GitHub).
Если положить папку `bin/` в репозиторий, то туда попадут временные файлы сборки. Это плохо, потому что:
* Они занимают много места.
* Они могут конфликтовать при сборке на другом компьютере.
* Они постоянно меняются, и история коммитов превратится в мусор.

## 5. Какой тип данных (`int`, `string`, `double`, `bool`) вы бы выбрали для хранения:
* **Фамилии** — `string` (текст).
* **Возраста** — `int` (целое число).
* **Среднего балла** — `double` (число с запятой, например 4.5).
* **Признака «студент отчислен / не отчислен»** — `bool` (истина/ложь, true/false).

## 6. Что выведет `Environment.ProcessorCount` на вашем компьютере? А на ноутбуке соседа? Почему цифры могут отличаться?
Команда выведет **количество логических ядер** процессора.
На моём компьютере это 12.
На ноутбуке соседа цифра может отличаться, потому что у нас разные процессоры. У кого-то 2 ядра, у кого-то 16. Это зависит от модели и мощности устройства.

## 7. Зачем вызывать `Console.ResetColor()` после смены цвета?
Чтобы вернуть консоль к стандартным цветам (обычно белый текст на чёрном фоне). Если этого не сделать, весь последующий текст в программе (и даже после её завершения) останется окрашенным в тот цвет, который мы установили последним. Это выглядит некрасиво и может сбивать с толку.
